+=================================================================+
|                      BIOS FILES INFORMATION                     |
+=================================================================+

Some emulators require BIOS files to work correctly. These are firmware
files from the original consoles and must be obtained legally.

AUTOMATIC CHECK (recommended):
  * Run:  Tools\diagnose.bat     (full health check + auto-repair)
  * Or:   python Launcher\launcher.py --check
Both list exactly which BIOS files are missing for YOUR library.

LEGAL WAYS TO OBTAIN BIOS FILES:
===================================================================

1. Extract from your own console hardware (100% legal)
2. Purchase from official sources
3. Some are available as freeware/abandoned

DO NOT download BIOS files from ROM sites - that is piracy.


REQUIRED BIOS FILES BY SYSTEM:
===================================================================

PLAYSTATION 1
-------------
Files needed:
  * scph1001.bin (USA BIOS)
  * scph5500.bin (Japan BIOS) - optional
  * scph5502.bin (Europe BIOS) - optional

Location: Emulators\RetroArch\system\

Without BIOS: some games may not boot or may have glitches.


SEGA DREAMCAST
--------------
Files needed:
  * dc_boot.bin (Dreamcast BIOS)
  * dc_flash.bin (Dreamcast Flash)

Location: Emulators\RetroArch\system\

Without BIOS: most games will not boot.


NINTENDO DS
-----------
Files needed:
  * bios7.bin (ARM7 BIOS)
  * bios9.bin (ARM9 BIOS)
  * firmware.bin (NDS Firmware)

Location: Emulators\RetroArch\system\

Without BIOS: the core falls back to high-level emulation (less accurate).


NEO GEO / ARCADE
----------------
Files needed:
  * neogeo.zip (Neo Geo BIOS - keep it zipped!)

Location: Emulators\RetroArch\system\

Without BIOS: Neo Geo games will not load.


GAME BOY ADVANCE
----------------
Files needed:
  * gba_bios.bin (GBA BIOS) - optional

Location: Emulators\RetroArch\system\

Without BIOS: uses built-in HLE (works fine for most games).


OPTIONAL BIOS FILES:
===================================================================

These improve accuracy but are not required:

SEGA CD / MEGA CD
  * bios_CD_E.bin (Europe)
  * bios_CD_U.bin (USA)
  * bios_CD_J.bin (Japan)

PC ENGINE CD
  * syscard3.pce

SEGA SATURN
  * saturn_bios.bin


HOW TO ADD BIOS FILES:
===================================================================

1. Obtain BIOS files legally
2. Copy to: Emulators\RetroArch\system\
3. Filenames must match EXACTLY (lowercase recommended)
4. Run Tools\diagnose.bat to verify


VERIFICATION:
===================================================================

Option A (automatic): run Tools\diagnose.bat

Option B (in RetroArch):
1. Launch any game and press F1 for the RetroArch menu
2. Go to: Information -> System Information
3. RetroArch lists every required file and whether it was found,
   including the expected MD5 checksums. Trust THOSE checksums -
   they always match the core version you have installed.


TROUBLESHOOTING:
===================================================================

"BIOS file not found"
   -> Check the filename matches exactly (lowercase!)
   -> Verify the file is in Emulators\RetroArch\system\
   -> neogeo.zip must stay zipped; do NOT extract it

"Invalid BIOS file" / game does not load
   -> File may be corrupted or the wrong region
   -> Compare MD5 in RetroArch: F1 -> Information -> System Information
   -> Try a different region dump (USA/EUR/JAP)

Game still does not load
   -> Check RetroArch logs in Emulators\RetroArch\logs\
   -> Run Tools\diagnose.bat for an automated diagnosis
