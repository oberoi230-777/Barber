  PORTABLE RETRO GAMING SUITE v3.0 — QUICK START
================================================================================

WINDOWS
  1. Copy this folder to a USB drive
  2. Run SETUP.bat  (or: SETUP.bat -Unattended -IncludeSampleRoms)
  3. Run LAUNCH.bat
  4. Optional free games:  Tools\download-roms.bat -System All

LINUX / MAC
  ./setup.sh --yes
  ./launch.sh

--------------------------------------------------------------------------------
LAUNCHER CONTROLS
--------------------------------------------------------------------------------
  Up/Down / D-pad / stick .... Navigate (any pad works)
  Enter / A .................. Select or launch
  ESC / B .................... Back / exit
  Left/Right / LB/RB / Tab ... Cycle category (Nintendo, Sega, Arcade...)
  Type letters ............... Live filter
  F2 ......................... Recent games
  F3 / C ..................... Categories
  F5 / Y (in game list) ...... Favorite
  F6 / V ..................... Favorites only
  F7 / E ..................... Hide/show empty systems
  R (systems list) ........... Rescan ROMs
  F1 ......................... Help
  F11 ........................ Fullscreen

--------------------------------------------------------------------------------
2-PLAYER JOYSTICKS
--------------------------------------------------------------------------------
  • Plug in TWO controllers before launching a 2P game
  • Launcher header shows "2P OK" when both are detected
  • P1 = first pad (or Arrows + Z/X/A/S + Enter)
  • P2 = second pad (or IJKL + F/G/R/T + B)
  • P3 / P4 = third / fourth pad (N64, arcade, etc.)
  • Hold Select/Back + Start = quit to launcher
  • Test pads: Tools\test-controller.bat

--------------------------------------------------------------------------------
ADD FREE / LEGAL GAMES
--------------------------------------------------------------------------------
  Tools\download-roms.bat                  (menu)
  Tools\download-roms.bat -System All      (popular systems sample pack)
  Tools\download-roms.bat -System Everything
  Tools\download-roms.bat -System NES -MaxFiles 10
  Tools\download-roms.bat -Query "tic80 cart"

  Catalog file (edit to expand forever, no code changes):
    Configs\free-games-catalog.json

  Manual ROMs go in:  ROMs\<SystemFolder>\
  Then press R in the launcher to rescan.

--------------------------------------------------------------------------------
ADD A NEW SYSTEM (future-safe)
--------------------------------------------------------------------------------
  1. Edit Configs\systems.json — add name/folder/extensions/core/players
  2. If the core is new, add it to Tools\ps-common.ps1 + setup.sh
  3. Run SETUP or Tools\update-system.bat -Action Cores
  4. Create ROMs\<Folder>\ and drop games in

--------------------------------------------------------------------------------
IN-GAME (RetroArch)
--------------------------------------------------------------------------------
  F1 menu · F2 save · F4 load · F8 screenshot
  Hold Space = fast-forward · R = rewind · ESC = quit

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

LEGAL
