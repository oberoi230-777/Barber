FIRST TIME SETUP (do this once)
=================================================================

EASY WAY (recommended):
1. Copy this folder to your USB drive
2. Right-click SETUP.bat -> "Run as administrator"
3. Follow the prompts (it installs Python, RetroArch, all cores)

ZERO-CLICK WAY (fully automatic):
1. Copy this folder to your USB drive
2. Run:  SETUP.bat -Unattended -IncludeSampleRoms
3. Done - sample games included!

LINUX / macOS:
1. Open a terminal in this folder
2. Run:  ./setup.sh --yes
3. Run:  ./launch.sh


LAUNCHING GAMES
=================================================================

1. Double-click LAUNCH.bat (or ./launch.sh)
2. Pick a system with Up/Down + Enter
3. Start typing to search, pick a game, Enter
4. Play!

TIP: press F1 inside the launcher for the full control list.


CONTROLS
=================================================================

IN LAUNCHER:
  * Arrow Keys / D-Pad ........ Navigate menus
  * Enter / A Button .......... Select / Launch
  * ESC / B Button ............ Back / Exit
  * Type letters .............. Search games live
  * F5 or Y ................... Favorite a game (*)
  * F6 or X ................... Show favorites only
  * R (systems view) .......... Rescan game library
  * F1 ........................ Help screen
  * F11 ....................... Toggle fullscreen

IN GAME:
  * Arrow Keys / D-Pad ........ Move
  * Z or A Button ............. Button A
  * X or B Button ............. Button B
  * Enter ..................... Start
  * Shift ..................... Select
  * F1 ........................ RetroArch menu
  * F2 ........................ Quick save
  * F4 ........................ Quick load
  * Space (hold) .............. Fast forward
  * ESC ....................... Exit game (back to launcher)


ADDING GAMES (ROMs)
=================================================================

METHOD 1: Automatic Download (free legal homebrew)
  * Run: Tools\download-roms.bat
  * Pick a system, or download the sample pack for all systems

METHOD 2: Manual Copy
  * Copy ROM files into ROMs\<system>\  (e.g. ROMs\NES\)
  * Zipped ROMs work for cartridge systems
  * Press R in the launcher to rescan

METHOD 3: Organize a messy folder
  * Run: Tools\organize-roms.bat -SourceFolder "C:\Downloads\ROMs"
  * Add -DryRun first to preview, -MoveFiles to move instead of copy


REQUIRED BIOS FILES (some systems only)
=================================================================

  * PlayStation 1 -> scph1001.bin
  * Dreamcast -> dc_boot.bin, dc_flash.bin
  * Nintendo DS -> bios7.bin, bios9.bin, firmware.bin
  * Neo Geo -> neogeo.zip (keep zipped!)

Place BIOS files in: Emulators\RetroArch\system\

Run Tools\diagnose.bat to see exactly which ones YOU are missing.
See Configs\BIOS-INFO.txt for the complete guide.

TROUBLESHOOTING (99% of problems)
=================================================================

STEP 1: run Tools\diagnose.bat and accept the auto-repair.
STEP 2: if it persists, check TROUBLESHOOTING.md (full guide).
STEP 3: Logs in Logs\ show exactly what failed.

Quick fixes:
* "Python not found" (or the LAUNCH window flashes and closes) -> run
  SETUP.bat (installs real Python automatically, skips the Store stub).
  If the Microsoft Store opens when you type python, you only have the
  stub: install from python.org or disable it under Settings -> Apps ->
  Advanced app settings -> App execution aliases
* Controller not working -> connect BEFORE launching; test with
  Tools\test-controller.bat; Win+R -> joy.cpl must list the pad
* Game won't load -> missing BIOS or core? diagnose.bat tells you
* Slow performance -> use blue USB 3.0 ports; close other programs;
  press F1 in game -> disable shaders
* No games showing -> add ROMs, then press R to rescan in launcher
