📋 FIRST TIME SETUP (Do this once)
═══════════════════════════════════════════════════════════════════════

1. Right-click SETUP.bat → "Run as Administrator"
   
2. Wait for setup to complete (downloads RetroArch and cores)
   • Downloads ~300-500 MB
   • Takes 5-15 minutes depending on internet speed
   
3. Optional: Download sample games when prompted

4. Done! Your gaming system is ready


🚀 LAUNCHING GAMES
═══════════════════════════════════════════════════════════════════════

1. Double-click LAUNCH.bat

2. Use arrow keys or controller to navigate

3. Select a system (NES, SNES, Genesis, etc.)

4. Select a game

5. Play!


🎮 CONTROLS
═══════════════════════════════════════════════════════════════════════

IN LAUNCHER:
  • Arrow Keys / D-Pad ........ Navigate menus
  • Enter / A Button .......... Select
  • ESC / B Button ............ Back/Exit
  • F11 ....................... Toggle fullscreen

IN GAME:
  • Arrow Keys / D-Pad ........ Move
  • Z or A Button ............. Button A
  • X or B Button ............. Button B
  • Enter ..................... Start
  • Shift ..................... Select
  • F1 ........................ RetroArch menu
  • F2 ........................ Quick save
  • F4 ........................ Quick load
  • Space (hold) .............. Fast forward
  • ESC ....................... Exit game


📥 ADDING GAMES (ROMs)
═══════════════════════════════════════════════════════════════════════

METHOD 1: Automatic Download (Legal ROMs)
  • Run: Tools\download-roms.bat
  • Select system
  • Downloads free homebrew games

METHOD 2: Manual Copy
  • Copy ROM files to correct folder in ROMs\
    Example: NES games go in ROMs\NES\
  • Supported formats listed in README.md
  • Games appear automatically in launcher


💾 REQUIRED BIOS FILES (Some systems only)
═══════════════════════════════════════════════════════════════════════

Some systems need BIOS files to work:
  • PlayStation 1 → scph1001.bin
  • Dreamcast → dc_boot.bin, dc_flash.bin
  • Neo Geo → neogeo.zip

Place BIOS files in: Emulators\RetroArch\system\

See Configs\BIOS-INFO.txt for complete guide

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

🔴 "Python not found"
   → Install Python from https://www.python.org/downloads/
   → Check "Add Python to PATH" during installation
   → Run SETUP.bat again

🔴 Controller not working
   → Connect before launching
   → Run Tools\test-controller.bat to verify
   → Check Windows Game Controller settings

🔴 Game won't load
   → Check if BIOS file is required (see BIOS-INFO.txt)
   → Verify ROM file is in correct folder
   → Try different ROM file

🔴 Slow performance
   → Use USB 3.0+ port (blue USB ports)
   → Close other programs
   → Disable shaders in RetroArch (F1 → Settings)

🔴 No games showing
   → Add ROM files to ROMs\ folders
   → Use Tools\download-roms.bat for free games
   → Restart launcher
